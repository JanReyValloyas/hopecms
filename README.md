# Hope, Inc. Customer Management System (CMS)

A 6-week capstone project for a 5-member BS Computer Science team.

## 🚀 Tech Stack
- React 18 + Vite
- Tailwind CSS
- Supabase (PostgreSQL + Auth)
- React Router v6
- Vitest + React Testing Library

## 📁 Branching Strategy
- `main` — production-ready code only
- `dev` — stable development base
- `feature/*` — new features (e.g. feat/login-page)
- `fix/*` — bug fixes
- `db/*` — database changes
- `test/*` — test files
- `docs/*` — documentation
