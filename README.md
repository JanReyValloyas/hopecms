# Customer Management System (CMS)
### Hope, Inc. | BS Information Technology Capstone Project | 6-Week Plan

---

## 📌 Project Overview
A full-stack Customer Management System built for Hope, Inc. to manage customer records, sales history, product catalogue, and user access rights. Built by a 5-member team over 3 sprints.

**Live Demo:** https://hopecms-589r.vercel.app

---

## 🚀 Tech Stack
| Technology | Purpose |
|---|---|
| React 18 + Vite | Frontend framework |
| Tailwind CSS | UI styling |
| Supabase (PostgreSQL) | Database + Authentication |
| React Router v6 | Client-side routing |
| Vitest + React Testing Library | Unit testing |
| Vercel | Deployment |

---

## 📁 Branching Strategy
| Branch | Purpose |
|---|---|
| `main` | Production-ready code only |
| `dev` | Stable development base |
| `feat/*` | New features (e.g. feat/login-page) |
| `fix/*` | Bug fixes |
| `db/*` | Database changes |
| `test/*` | Test files |
| `docs/*` | Documentation |

> ⚠️ No direct pushes to `main` or `dev`. All changes must go through Pull Requests.
